- 建立：2026-11-14

- 适用版本：`apps/web` v2 人文关怀版（分支 `feature/v2-web`，不在 main 上发布）

## 一、测试基线规则

1. 测试基线 = 全部 11 屏接入路由后的 `feature/v2-web` 最新完整 SHA，由项目经理在群里公布，不接受「以最新代码为准」这类模糊口径。
2. 每项测试记录 **PASS / FAIL / BLOCKED**，并保留实际执行证据（浏览器或真机截图、汇总行原文、控制台输出）。
3. **未实测的项目不得标记 PASS**，桌面模拟不能替代真机结论。
4. 发现 BUG 交程序员修复，修复后以新 SHA 完整回归，不允许只回归单点。
5. 本清单全部项目通过之前，不签发 v2 产品化测试 PASS，Cloudflare 线上版本保持现状。
